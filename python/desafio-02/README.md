Challenge 2 - Test Data Generator

Objective

Create and organize test user data using Python data structures.

What the program does

The program:
- Stores multiple users in a list os dictionaries
- Counts the total number of users
- Iterates though the users
- Displays each users's information

Python concepts practiced
- Lists
- Dictionaries
- Variables
- for loops
- len()
- enumarate()
- Dictionary key acces
- .format()

QA connection

Test data is commonly used in software testing.

This project simulates a small set of user data that could be used when testing registration, login, or other user-related features.
